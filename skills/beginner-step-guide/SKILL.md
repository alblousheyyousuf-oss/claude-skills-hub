# Beginner step guide

- Start with "where we are" (✅ done / ⏳ next) when the user asks "what now?".
- One screen at a time; quote exact button labels in English as they appear; arrows for menu paths (A ← B ← C in RTL text).
- Each guide: what it is (2–3 lines) · steps · settings table · troubleshooting table keyed by the message the user will see · what to send back (photo of X).
- Say clearly what is not needed (e.g. "don't create an App"), and which parts need the PC vs. not.
- Remind once: download deliverables before a cloud session ends.
- Short sentences; Arabic with English terms in parentheses.
