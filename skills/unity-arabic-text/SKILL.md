# Arabic text in Unity

- TextMeshPro does not shape Arabic (no joining, wrong direction). Ship **pre-rendered images** generated by a script; any new text = regenerate.
- Generator: PIL `ImageFont.truetype(..., layout_engine=ImageFont.Layout.RAQM)` (needs libraqm). OFL fonts used: Reem Kufi (Arabic titles), Noto Kufi Arabic (body), Josefin Sans (Latin). Download from raw.githubusercontent.com.
- Avoid dark fringes: RGB = text colour on **every** pixel; alpha = the mask. Soft glow = blurred mask added to alpha.
- Unity resizes non-power-of-two textures on import → read the **original sizes from a generated table** (e.g. `OLTexSizes.cs`), not from the imported texture.
- A text quad reads correctly when its +Z points away from the viewer; billboard toward the head for floating labels.
- Palette used for OmanLight: cream (255,241,214), gold (242,180,85).
