# Art research sprint

Budget: ≤15 searches, ≤1 report page, one round of questions.
1. Re-state the locked core (`brief-lock`). Research only *how* to realise it.
2. Global references: 5–8 works with one measurable popularity fact each and the **transferable decision** (behaviour, not look).
3. Science (reuse, don't re-search): curvature preferred (Bar & Neta 2006); mid fractal complexity; MAYA typical+novel (Hekkert 2003); awe = vastness + accommodation, weakened by familiarity; colour liked via associated objects. → meaning/material/colour familiar, form/scale/behaviour novel.
4. Culture: principles and phenomena, not icons; flag clichés (for the Gulf: dhow, falcon, camel, dates, incense burner, khanjar).
5. Output: table *decision → source → how it serves the core*, then 3 options that **all keep the core**.
